# 掌控

平板或手机用浏览器操作同一局域网里的一台 Windows。电脑端提供网页，画面由 Windows 远程桌面直接编码，文字保持清晰。

平板不用安装。电脑和手机要连同一台路由器，电脑插网线、平板连 Wi-Fi 也可以。不经过公网，也不需要注册账号。

## 运行条件

- Windows 10 / 11 专业版、企业版或教育版。家庭版不能接收远程桌面。
- 电脑已开启远程桌面，本机 `3389` 端口可用。
- 掌控的窗口保持打开。关掉窗口，平板就连不上了，窗口可以最小化。

连上之后，电脑面前的屏幕会锁定。这是 Windows 远程登录的正常行为。

## 使用

1. 解压电脑端压缩包，双击「掌控」。整个文件夹都要留着，只拷贝 exe 打不开。
2. 浏览器会打开本机页面，上面有二维码、局域网地址和访问密码。访问密码写在程序旁边的 `config.json` 里，第一次运行时自动生成。
3. 平板连上同一台路由器，用浏览器扫二维码或输入页面上的地址。
4. 先填访问密码，再填这台电脑的 Windows 用户名和密码。
5. 分辨率在平板页面上选。「跟随平板」按平板的物理像素请求，也可以选 2560×1600、2560×1440 等预设。换分辨率会重新连接，不会改电脑显示器本身的分辨率。

默认端口是 `8765`。再双击一次已经在运行的「掌控」，只会重新打开本机页面。

## 从源码运行

需要 Python 3.12。

```bat
python -m pip install -r requirements.txt
python -m zhangkong
```

也可以双击 `start.bat`，它会在缺依赖时先安装，再启动。

常用参数：

```bat
python -m zhangkong --check
python -m zhangkong --no-browser
```

`--check` 只测试本机远程桌面能否握手，不会登录。`--no-browser` 启动时不打开浏览器。

`config.json` 含访问密码，已在 `.gitignore` 里，不要提交。

## 本机官网

`site` 目录是下载页。双击 `打开官网.bat`，页面只在本机打开：<http://127.0.0.1:8780/>。别人访问不了这个地址，搜索引擎也收不到。

## 目录

| 路径 | 内容 |
| --- | --- |
| `zhangkong/` | 电脑端服务：网页、本机代理、启动逻辑 |
| `zhangkong/web/` | 平板打开的页面 |
| `site/` | 官网和 Windows 安装包 |
| `掌控.spec` | 打包电脑端用的 PyInstaller 配置 |
| `start.bat` | 从源码启动 |
| `打开官网.bat` | 在本机打开官网 |
